# Módulo 03 — Redes (fundamento central)

Redes são a espinha dorsal de quase toda investigação de segurança: um
atacante quase sempre precisa se comunicar pela rede em algum momento —
para entrar, para executar comandos remotamente, ou para roubar dados
(exfiltração). Este módulo formaliza o que só usamos de leve no Módulo
01 (`ss`, `ip`) e no Módulo 02 (Sysmon Event ID 3).

Ao final deste módulo, você deve conseguir olhar para uma conexão de
rede e responder: **quem está se comunicando, com quem, qual IP, qual
porta, qual protocolo, é isso normal ou suspeito?**
