# Módulo 05 — Wi-Fi / Wireless Security

Este módulo cobre 802.11, o funcionamento de SSID/BSSID, canais e
frames, além da evolução WPA → WPA2 → WPA3. Onde fizer sentido, usamos o
adaptador **AR9271** mencionado nas suas instruções — sempre em
laboratório próprio, rede própria ou ambiente explicitamente autorizado
(nunca contra terceiros), conforme o `CLAUDE.md` deste repositório.

O objetivo é **entender → monitorar → analisar → detectar → defender**,
não ofensivo por si só.
