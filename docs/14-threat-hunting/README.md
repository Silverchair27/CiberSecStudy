# Módulo 14 — Threat Hunting

Até aqui, sempre investigamos a partir de um **alerta** que já disparou.
**Threat Hunting** é o oposto: procurar ativamente por ameaças que
**nenhum alerta ainda detectou** — partindo de uma hipótese, não de uma
notificação.
