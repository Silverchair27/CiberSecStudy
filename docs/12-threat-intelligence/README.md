# Módulo 12 — Threat Intelligence

Até aqui, investigamos alertas e telemetria com base no que
observamos localmente. **Threat Intelligence** adiciona uma camada de
contexto **externo**: o que já se sabe, na indústria, sobre atacantes,
campanhas e infraestrutura maliciosa — transformando um IP ou hash
isolado em algo com história e contexto.
