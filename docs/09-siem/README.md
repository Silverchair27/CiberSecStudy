# Módulo 09 — SIEM

Depois de aprender a investigar um alerta (Módulo 08), voltamos um
passo: como esse alerta é **gerado** em primeiro lugar. Um SIEM
(*Security Information and Event Management*) é o sistema que
centraliza logs de toda a organização e os transforma em alertas
acionáveis.
