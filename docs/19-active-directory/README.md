# Módulo 19 — Active Directory

Active Directory (AD) é o coração da maioria dos ambientes corporativos
Windows — gerencia usuários, grupos, políticas e autenticação de toda
a organização. É também um dos alvos mais valiosos para um atacante:
comprometer o AD frequentemente significa comprometer a organização
inteira.
