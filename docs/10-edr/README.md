# Módulo 10 — EDR

Se o SIEM (Módulo 09) centraliza logs de toda a organização, o **EDR**
(*Endpoint Detection and Response*) foca profundamente em **um único
host**: telemetria detalhada de processos, arquivos, registry e rede,
com a capacidade de **agir** diretamente naquele endpoint (isolar,
matar processo, coletar evidência).
