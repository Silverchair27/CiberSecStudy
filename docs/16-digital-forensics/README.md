# Módulo 16 — Digital Forensics

Toda fase de Incident Response (Módulo 15) depende de **evidência**
bem coletada e analisada. Digital Forensics aprofunda como reconstruir,
com rigor, exatamente o que aconteceu em um sistema — timeline,
artefatos de sistema de arquivos, memória, e artefatos específicos de
Windows/Linux/browser.
