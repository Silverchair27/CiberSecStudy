# lab/

Setup e passo a passo dos laboratórios práticos (máquinas virtuais,
configuração de Sysmon, laboratório de Active Directory, topologia de
rede de estudo, etc.).

Cada laboratório deve ter sua própria subpasta com um `README.md`
descrevendo: objetivo, topologia/ambiente, passos de setup e como
reproduzir os exercícios associados (que ficam documentados em
`../reports/` ou `../docs/`).
